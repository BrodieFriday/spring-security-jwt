# Spring Security JWT - Field Notes

A modern Spring Boot application demonstrating secure authentication using **Spring Security** and **JWT**.

## Features

- **JWT-based Authentication** with Spring Security
- **Custom UserDetails** implementation
- **Secure token validation** and filtering
- **RESTful API** with authentication endpoints
- **PostgreSQL** support via Docker
- **Lombok** + **MapStruct** for clean code
- **H2** in-memory database for testing

## Tech Stack

- **Java 21**
- **Spring Boot 3.5.0**
- **Spring Security**
- **Spring Data JPA**
- **JJWT** (JSON Web Token library)
- **PostgreSQL**
- **Lombok**
- **MapStruct**
- **Maven**
